# MDSNet

This repository accompanies **MDSNet: Exploring Refined Speech Representations for Screening Mental Disorders**. The following resources are provided to support reproducibility and academic research.

## 1. Code for Compared Methods

The repositories and project pages used as references for the compared methods are listed below.

### Non-pre-trained supervised methods

- **DepAudioNet:** https://github.com/adbailey1/DepAudioNet_reproduction
- **vowel-CNN:** https://github.com/HUBBS-Lab
- **ConvBiLSTM:** https://github.com/pingcheng-wei/depressionestimation
- **Vlad-GRU:** https://github.com/speechandlanguageprocessing
- **ABAFnet:** https://github.com/xuxiaoooo/abafnet

### Self-supervised learning methods

- **ReCLR:** Please refer to the implementation information provided in the original paper.
- **wav2vec 2.0:** https://github.com/facebookresearch/fairseq/tree/main/examples/wav2vec
- **HuBERT:** https://github.com/bshall/hubert
- **DSPA:** https://github.com/IntelliDAL/Speech/tree/master/FD-learnableFilters

These repositories are maintained by their respective authors or organizations. Please consult each repository for its installation instructions, dependencies, and license terms.

## 2. Dataset Usage Policy

All datasets must be used in accordance with their original licenses, data-use agreements, ethical approvals, and access requirements.

- The datasets and associated metadata may be used only for legitimate academic and non-commercial research unless explicit written permission for another use has been granted by the corresponding data owner.
- Commercial use, unauthorized redistribution, resale, or sublicensing is prohibited where the applicable license or data-use agreement imposes such restrictions.
- This repository does not redistribute raw speech recordings, participant information, clinical labels, or other sensitive data. Users must obtain the data directly from the official provider and complete any required application or agreement.
- Users must protect participant privacy and must not attempt to identify, contact, or link participants to external information.
- Raw recordings, annotations, and derived files containing sensitive information must not be uploaded to public repositories.
- Publications and derivative work must cite the original dataset papers and acknowledge the data providers as required by their respective licenses.
- If a conflict exists between this policy and an original dataset license or data-use agreement, the original terms take precedence.

By accessing or using the datasets, users acknowledge that they are responsible for complying with all applicable licenses, institutional requirements, ethical standards, and local laws.
